# Budget Tracker

## Project Description

This project is a Budget Tracker application created using HTML and CSS.

For Week 3, the focus was on improving the visual design of the existing Budget Tracker without adding new functionality. CSS was used to create a clean, professional, and user-friendly interface.

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Color Palette

The application uses a small and consistent color palette:

* **Blue** – used for the main heading and buttons
* **Teal** – used for the table header and secondary headings
* **White** – used for the cards and form areas
* **Light gray** – used for the page background
* **Dark blue-gray** – used for normal text
* **Light gray-blue** – used for borders

CSS variables were used to keep the colors consistent throughout the application.

## Typography

Two Google Fonts were used:

* **Poppins** – used for main headings and table headings
* **Inter** – used for body text, labels, form inputs, buttons, and table content

The font pairing creates a clear visual hierarchy and improves readability.

## Add Expense Form

The Add Expense form was styled using CSS to improve its appearance and usability.

The form includes:

* Proper padding
* Margins for spacing
* Styled labels
* Consistent input fields
* Borders
* Rounded corners
* A styled Add Expense button
* Button hover effects

## Expense Table

The expense table was improved with:

* A colored table header
* Padding inside table cells
* Borders for structure
* Alternating row colors
* Row hover effects
* Rounded corners
* Consistent typography

These changes make the table easier to read and more visually organized.

## CSS Box Model

The CSS Box Model was intentionally used throughout the application.

### Margin

Margins were used to create space between the heading, form, and table.

### Padding

Padding was used inside cards, form inputs, buttons, and table cells to improve spacing.

### Border

Borders were used to define the boundaries of the heading, form, inputs, and expense table.

### Border Radius

Border radius was used to create rounded corners and give the application a softer, modern appearance.

The main sections of the application are presented as separate visual cards:

1. Page Heading
2. Add Expense Form
3. Expense Table
