# Budget Tracker

A simple Budget Tracker website built with HTML and CSS.

## Features

- Expense table
- Add Expense form
- Food category
- Transport category
- Rent category
- Entertainment category
- Other category
- Sample expense data
- Budgeting tips video
- How to use section
- Table hover effects
- Input focus effects

## Technologies Used

- HTML5
- CSS3

## Project Files

- `index.html`
- `style.css`
- `README.md`

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. The Budget Tracker will be displayed.

The Add Expense button is not functional yet. JavaScript will be added in a later week to make the tracker interactive.
